# Search Console and Yandex Submission Checklist

## Google Search Console

1. Open the property for `arvectum.com`.
2. Go to `Sitemaps`.
3. Submit:

   `https://arvectum.com/sitemap.xml`

4. Use `URL Inspection` for:
   - `https://arvectum.com/`
   - `https://arvectum.com/about.html`
   - `https://arvectum.com/solutions.html`
   - `https://arvectum.com/solutions/procurement.html`
   - `https://arvectum.com/materials.html`
   - `https://arvectum.com/materials/how-to-choose-first-process.html`
5. Request indexing where available.

## Yandex Webmaster

1. Open the site `https://arvectum.com`.
2. Check `robots.txt`.
3. Submit:

   `https://arvectum.com/sitemap.xml`

4. Use page re-crawl / переобход for:
   - `https://arvectum.com/`
   - `https://arvectum.com/about.html`
   - `https://arvectum.com/solutions.html`
   - `https://arvectum.com/solutions/procurement.html`
   - `https://arvectum.com/materials.html`

## Notes

- Do not expect instant indexing after submission.
- Do not re-submit the sitemap every hour.
- Re-submit again only after meaningful changes in `public/sitemap.xml`.
- Track results over `7`, `14` and `30` days.
