2. Open `https://arvectum.com/` and verify the homepage H1.
3. Open `https://arvectum.com/sitemap.xml`.
4. Open `https://arvectum.com/robots.txt`.
5. Open `https://arvectum.com/favicon-preview.html`.
6. Run `npm run check:production` after deploy if hosting changed.
7. Submit `https://arvectum.com/sitemap.xml` to Google Search Console.
8. Submit `https://arvectum.com/sitemap.xml` to Yandex Webmaster.
9. Check indexing after `3`, `7`, `14` and `30` days.
